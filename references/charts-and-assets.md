# 汇报图表与相关图片

用于实验数据图、论文机制示意图及PPT图表或外部素材；根据当前请求只执行必要步骤，不自动启动整套汇报。制作决策、选图理由、检索记录及QA结果保存在work；不放进正文或讲稿。论文原图的Figure / Panel和简短文献来源放在对应图片下方，相对图片实际显示范围水平居中；多图分别居中或整体组合共用图注时以整体居中。背景素材注明可靠来源；详细定位另存备注与工程清单，不自动添加重复的灰色页脚。外部素材署名按许可落实。

## 生成模型与真实证据

用户长期要求新制作的汇报图使用Image2：生成原创示意图、背景或插画时，使用明确支持并实际可选用Image2的图像生成能力；核对内容并标为示意，勿把生成图当作论文实验结果。当前工具若没有模型选择或身份验证能力，不得声称使用了Image2，也不悄悄替换为其他模型；向用户说明能力，继续论文分析、引用原图及其他不依赖生成模型的工作。当前任务明确指定其他模型或不使用生成图时优先遵从。

用户同时明确要求真实结果与数据表达不变：论文结果优先直接取自该论文Figure / Panel，允许保持数据语义的裁剪、放大、组合及独立添加箭头、框选和中文标注；不通过生成模型重绘或臆造实验曲线、坐标、数字、图例。图像直接提取、调整显示与PPT可编辑文字形状不属于用其他模型生成新图。若确需绘制可核实的定量数据图，而Image2结果不能保证数值正确或无法核验，说明与模型偏好的冲突，并就可复核数据绘图、原图或其他方案取得用户选择；不要伪造可编辑性或未经同意擅改模型要求。Image2输出通常为位图，文字、标注、表格及PPT布局应可编辑，交付时说明图内部编辑能力。

## 从数据到汇报图

先识别字段含义、单位、样本量、缺失值、分组、重复实验与误差定义，再根据论文问题选择图型；异常值只作为核查线索，不擅自删除。按需调用可用的scipilot-figure-skill辅助数据概览与选图；简单CSV数据图可用`scripts/research_chart.py`按规格绘制，投稿科研图按可用的nature-figure流程处理，无需对同一任务让各工具重复绘图。论文机制示意先核对原文对象和关系，适当使用可编辑形状或相应科研绘图工具，不将示意当作实验结果。PPT图表结合本节与汇报流程处理；普通组会图不必询问目标期刊。

| 数据与问题 | 常用表达 |
|---|---|
| 时间、迭代或连续参数的变化 | 折线，必要时配误差带 |
| 不同方法的单项指标 | 点图或横向条形，标明单位与基线 |
| 各组原始样本分布 | 散点叠加箱线；样本充分时再考虑小提琴 |
| 两个连续变量关系 | 散点；拟合与相关性仅在适用时加入 |
| 矩阵、相关性或参数扫描 | 热力图，明确色标与缺失值 |
| 延迟、误差等累计分布 | ECDF；关注尾部时明确分位数 |
| 多目标性能 | 散点或小多图，按指标分别显示单位 |
| 构成比例 | 堆叠条形；保留共同分母与总量 |

结合当前目标判断而非按表机械选图。区分类别与连续量，禁止为美观连接无序类别、隐去样本分布或制造显著性。误差棒必须明确SD、SEM或区间；已有汇总值不能伪造原始样本。直方图按实际统计口径检查纵轴为频数、密度或比例；ECDF检查为累计比例。允许有依据的自定义标签，不按固定词表强行改写。

优先从用户数据、论文表格、开放数据及作者代码取得数值。只有图像时使用清晰原图；确需数字化，标注近似提取并核对误差。保存绘图脚本、数据来源及SVG/PNG，使用放入幻灯片后的实际尺寸检查轴标签和图例。`research_chart.py` 的JSON可选 `figsize: [宽, 高]`（英寸）、`png_dpi`、`export_pdf: true`；未指定时沿用10×5.6英寸、180 DPI和SVG/PNG。记录实际参数、输入路径及数据哈希；PDF、尺寸和DPI须结合目标用途核对。需要原生可编辑图表时使用后端的原生图表协议，逐项验证；矢量图片不冒称数据可编辑。

所有插入演示的论文图、图表和背景应按最终显示尺寸保证清晰：优先原始矢量图或高分辨率原图；从PDF提取时直接针对目标区域以足够分辨率渲染，或在兼容时保留矢量，不先将整页低分辨率截图再放大。保留坐标、单位、图例和必要图注，插入后按实际投影尺寸查看细字和线条，也检查裁剪边缘。插值放大不能恢复细节；若可获得的原图仍模糊，寻找可靠的高清来源、基于真实数据重绘或如实说明，不能凭外观编造数据。按素材原生质量判断，不承诺所有原始图片均可无损变清晰。

## 检索图片与背景

从论文对象、设备、应用场景和本页需要解释的内容构造查询，使用可用web/image search。优先作者项目页、机构或设备官方网站、开放授权素材库；打开来源页并实际查看候选，核对对象、分辨率、许可及署名要求。不能只凭缩略图或文件名判断。

素材记录包括来源URL、作者/机构、用途、许可依据、下载位置和使用页。不可确认复用许可时选择许可清楚的替代品；可链接原来源。下载只用于任务材料，遵守工具的媒体访问约束。

论文原图解释方法或实验，外部图片说明背景与现实场景，自绘图解释概念。外部图片不能冒充论文实验装置或结果。背景选择低干扰构图并检查对比度；实验页优先清晰底色，装饰图不挤占证据区。没有合适图片时使用简单背景或准确示意图，不以不相关科技图填空。

需要生成概念插图时按imagegen技能执行，并依上述Image2偏好核验模型和实际能力；标为示意，不得用生成图片改造数据证据。

## 本地图表入口

该入口保留给用户允许使用可复核科学绘图工具的情形；不能绕过当前Image2指定。用本skill的`.runtime/Scripts/python.exe scripts/research_chart.py <spec.json>`执行；spec的相对路径以spec所在目录解析。示例：
```json
{"kind":"line","data":"measurements.csv","source":"paper Fig.4 / supplied measurements","x":"load","y":"latency","group":"method","xlabel":"负载 (%)","ylabel":"时延 (ms)","output":"charts/latency"}
```
支持line/scatter/bar/box/violin/hist/ecdf/heatmap，生成SVG、PNG与来源和数据哈希记录。热力图用columns明确数值列；折线误差带用lower、upper和interval_definition；重复x要明确分组或在上游完成有记录的统计。脚本不自动汇总数据或推断显著性。SVG是图形输出，不自动成为带工作簿的PPT图表；需要后者使用原生Chart协议。修改覆盖需overwrite=true。配色、标签、单位、样本语义和最终缩放仍需读图复核。
